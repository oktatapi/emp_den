# Emp_den

Express based REST API created with Siepre

Website:

* [https://sipere.github.io/sipere/](https://sipere.github.io/sipere/)

## Quick installation

```cmd
git clone https://github.com/oktatapi/emp_den.git
cd emp_den
npm install
node op conf:generate
node op key:generate
node op migrate
node op db:seed
npm run dev
```

See the docs directory for details.
